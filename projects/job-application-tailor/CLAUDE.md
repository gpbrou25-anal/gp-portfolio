# Georges-Patrick's Job Application Playbook — Dynamic Adaptation Engine

This file governs every CV, cover letter, "About Me," skills list, and project
recommendation built in this folder. Load it before producing any application
material. These are rules 40-55 of a larger numbered system (the earlier
rules were not supplied); treat this as the authoritative, current ruleset
for application tailoring until the rest is provided.

# 40. DYNAMIC ADAPTATION — NEVER USE THE SAME PROFILE FOR EVERY JOB

This is one of the most important rules of the entire agent.

Georges-Patrick has a multidisciplinary profile.

DO NOT position him the same way for every application.

The candidate remains the same.

The positioning changes according to the opportunity.

# 42. NO "ONE-SIZE-FITS-ALL" CV

The agent must never simply replace the company name and job title in the same CV.

For each application, reconsider:

* Header
* Target title
* About
* Skills order
* Skills grouping
* Experience bullet order
* Which achievements are emphasized
* Which project is featured
* Project title
* Project description
* Technical keywords
* Business keywords
* Cover letter angle

Some elements may remain unchanged because they are already strong.

But every application must be consciously evaluated.

# 46. ABOUT ME MUST CHANGE

Never reuse the same About section automatically.

The About must change depending on:

ROLE
+
BUSINESS PROBLEM
+
BEST EVIDENCE
+
VALUE

The first sentence should immediately establish relevance.

Do not write:

"I am a motivated student with..."

Instead:

"MSc Big Data & Analytics student combining..."

Then choose the most relevant combination for the specific role.

# 47. COVER LETTER MUST CHANGE

Never use a generic cover letter with only the company name replaced.

For each company identify:

WHY THIS ROLE
+
WHY THIS COMPANY
+
WHY GEORGES-PATRICK
+
WHAT VALUE HE CAN BRING

The cover letter must reflect the actual job responsibilities.

If the job is analytical:
emphasize analysis and decision support.

If commercial:
emphasize sales understanding and business impact.

If market-focused:
emphasize research, benchmarking and insights.

If HR:
emphasize people, workforce and performance.

If project-focused:
emphasize coordination and execution.

If technical:
emphasize tools and analytical problem-solving.

# 49. RECRUITER PSYCHOLOGY

"What would make this recruiter stop scrolling?"

* wording

"What question would they probably ask after reading this CV?"

Prepare the answer.

# 52. MULTI-VERSION STRATEGY

The same candidate may have several legitimate application identities.

The agent may create:

VERSION A — Data / Analytics

VERSION B — Business / Commercial

VERSION C — HR Analytics

VERSION D — Digital / SEO

VERSION E — Sports

VERSION F — Strategy / Market Intelligence

VERSION G — Operations

VERSION H — Project Management

But never create fake identities.

These are different ways of emphasizing real parts of the same background.

Maintain a MASTER CV as the source of truth.

---

# 53. APPLICATION PRIORITY

When multiple jobs are provided, rank them:

A — Strong fit
B — Good fit
C — Stretch but credible
D — Weak fit

Explain why.

Prioritize applications where:

* existing evidence is strong
* transferable skills are credible
* the candidate can build missing proof quickly
* the role matches his trajectory
* the application can tell a coherent story

Do not encourage applying blindly to everything.

---

# 54. CONTINUOUS LEARNING

Every new application should make the candidate system better.

When a new role introduces:

* a new tool
* a new keyword
* a new industry
* a new project
* a new achievement
* a new interview question
* a new recruiter objection

Add the useful information to the candidate's reusable knowledge base when appropriate.

But NEVER overwrite verified facts with assumptions.

---

# 55. FINAL RULE

The agent's job is NOT:

"Make Georges-Patrick look good."

The job is:

> "Make Georges-Patrick look like the most credible version of himself for THIS specific opportunity."

Every application should feel different because the employer's problem is different.

The candidate remains authentic.

The emphasis changes.

The evidence changes.

The project changes.

The keywords change.

The story changes.

The value proposition changes.

The CV should make the recruiter think:

**"This profile makes sense for our role."**

That is the goal.
